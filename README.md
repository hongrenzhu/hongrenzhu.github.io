# Hongren Zhu — personal website

A bilingual, responsive portfolio at **https://hongrenzhu.github.io/**, based on the October 2026 CV.

## Files

- `index.html` — English homepage.
- `index-zh.html` — Chinese homepage; keep both languages in sync.
- `assets/site.css` — shared responsive and print styles.
- `assets/site.js` — optional navigation enhancements; all content, links and project details work without it.
- `assets/Hongren_Zhu_CV.pdf` — the downloadable CV, copied without modification from the supplied version.
- `assets/favicon.svg`, `robots.txt`, `sitemap.xml` — site icon and discovery metadata.

## Updating

Edit both HTML pages for content changes. To replace the downloadable CV, overwrite `assets/Hongren_Zhu_CV.pdf` using the same filename. Update the sitemap dates when page content changes. Commit to `main`; the existing GitHub Pages deployment publishes the repository root.

No package installation, build step, third-party fonts, analytics or backend is required. Older `main.tex` and `demo.png` files are retained as historical assets and are not used by the current site.
